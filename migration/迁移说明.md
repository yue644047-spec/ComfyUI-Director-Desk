# 内网迁移说明（ComfyUI + 导演台 + clora Python 环境）

## 一、打包产物（源机器已生成）

- `migration/clora_env.tar.gz` —— clora Python 3.10 环境（torch 2.11+cu130、huggingface_hub、
  imageio-ffmpeg 等全部依赖，约 7GB，由 conda-pack 打包，可整体迁移）

## 二、需要拷贝到内网机器的内容

| 内容 | 说明 |
|---|---|
| `D:\app\comfyui` 整个目录 | 含 models（几十 GB）、comfy_extras、web、custom_nodes、main.py 等 |
| `migration\` 目录 | 本说明 + clora_env.tar.gz + 三个 .bat |

## 三、目标机器安装步骤（Windows 10/11 + NVIDIA 显卡）

1. 拷贝上述内容到 `D:\app\comfyui`
2. **安装显卡驱动**（需要支持 CUDA 13 的 NVIDIA 驱动，≥ 580 版本建议）
3. 双击 `migration\install_env.bat`
   - 解压环境到 `D:\ProgramData\anaconda3\envs\clora`（**与源机器同路径**，可避免前缀问题）
   - 自动执行 conda-unpack 修复路径 + torch 自检
4. 双击 `migration\start_comfyui.bat` → 等待启动完成 → 打开 http://127.0.0.1:8188
5. 双击 `migration\start_director.bat` → 打开 http://127.0.0.1:9081
6. 在导播台里把提示词/角色等数据重新编辑或导入（或直接使用拷贝过来的 web\state.json）

## 四、注意事项

- **无需互联网**：生成、分镜解析、自动保存、拼接、字幕、角色固定、模型选择全部本地。
- **两个云端功能**（内网不可用，除非有内网 OpenAI 兼容服务并在设置里改 Base URL）：
  AI 写剧本（DeepSeek）、素材 AI 打标签（Qwen-VL）。
- **新模型**需在外网下好后拷贝进内网的 models 目录。
- **字幕字体**：需要 `C:/Windows/Fonts/simhei.ttf`，没有的话改 `web\.env` 的 `FONT` 变量。
- **其他机器访问**（可选）：把启动脚本中绑定 127.0.0.1 改为 0.0.0.0，并放行防火墙端口。
  需要的话可在 main.py 启动参数加 `--listen 0.0.0.0`，web/app.py 修改
  `ThreadingHTTPServer(("127.0.0.1", port)` → `("0.0.0.0", port)`。
- **python_embeded**（comfyui.exe 用的便携 Python）：若只用 .bat 启动则无需拷贝；
  若用 comfyui.exe 启动则整个目录已包含。
- **验证**：打开 8188 的 ComfyUI 能加载工作流；9081 导播台能提交生成即迁移成功。

## 五、常见问题

- torch 自检报错：先看是不是路径不一致；用同路径解压可避免。
- 显存/生成变慢：确认新机器显卡型号与驱动；H3 用 极速/均衡 档，Wan2.2 用 5B。
- 端口被占用：改 .bat 里的端口或先关掉占用进程。


## 六、代码更新后的增量迁移（日常迭代用）

代码改完不需要重新打包 Python 环境。源机器上双击 `migration\make_incremental.bat`：

- 默认生成 `incremental_时间戳.zip`（约 30MB，含代码/前端/工作流/文档，不含用户数据）
- `make_incremental.bat withstate` 可连镜头/角色数据（web\state.json）一起打包
- 内网机：把 zip 解压覆盖到 `D:\app\comfyui`，重启两个服务即生效
- 仅当 pip/conda 依赖变化时，才需要重新执行 conda-pack 并更新 `clora_env.tar.gz`
